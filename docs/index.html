Comment rejoindre
1
Télécharge et lance le launcher Double-clique sur Petravox.Launcher.exe. Si SmartScreen apparaît, voir la section ci-dessus.
2
Connecte ton compte Microsoft Clique sur "Se connecter" → un code s'affiche → entre-le sur microsoft.com/devicelogin. Ton compte doit posséder Minecraft Java Edition.
3
Clique sur Jouer Le launcher installe Forge et tous les mods automatiquement (~2–5 min la première fois). Tu n'as rien d'autre à faire.
4
Rejoins le serveur Ajoute srv01.uniheberg.fr:25540 dans Minecraft et connecte-toi !

FAQ
Je n'ai pas Minecraft Java Edition, je peux quand même jouer ? ▾
Non, Minecraft Java Edition est requis. Tu peux l'acheter sur minecraft.net. Le launcher gère l'authentification mais pas la licence.
Le launcher ne se lance pas / fenêtre noire ▾
Vérifie que tu utilises la dernière version. Si le problème persiste, un fichier launcher_error.log est créé dans %appdata%\.petravox\ — envoie-le à un admin pour diagnostic.
Minecraft crash au démarrage ▾
Essaie d'augmenter la RAM dans les Paramètres du launcher (6–8 Go recommandé). Si le crash persiste, vérifie les logs dans %appdata%\.petravox\minecraft\logs\.
Les mods se mettent-ils à jour automatiquement ? ▾
Oui. Le launcher vérifie à chaque lancement si le modpack a changé et resynchronise automatiquement les mods si nécessaire.
Où sont stockés les fichiers Minecraft ? ▾
Dans %appdata%\.petravox\minecraft\ — séparé de ton installation Minecraft normale pour ne pas interférer.
Comment signaler un bug ? ▾
Ouvre un ticket sur GitHub Issues en joignant le fichier launcher_error.log si le launcher est concerné.
