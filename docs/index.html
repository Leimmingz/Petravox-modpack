Deux façons de jouer, un seul monde

Le modpack « Fantasy vs. Science » mêle magie, exploration et automatisation. À toi de choisir ta voie — ou de faire les deux.

Démarrer

Rejoindre en quatre étapes

Aucun fichier à déplacer, aucun Forge à installer soi-même.

  1. Télécharge le launcher

    Lance Petravox-Setup.exe et suis l’installation. Un raccourci est créé sur le Bureau et dans le menu Démarrer.

  2. Connecte ton compte Microsoft

    Clique sur « Se connecter » : un code s’affiche, tu le saisis sur la page Microsoft qui s’ouvre. Ton compte doit posséder Minecraft : Java Edition.

  3. Clique sur Jouer

    Java, Minecraft, Forge et les 216 mods s’installent tout seuls. Compte une dizaine de minutes la première fois, puis quelques secondes ensuite.

  4. Rejoins le serveur

    Active « Rejoindre le serveur directement » dans les Paramètres du launcher, ou ajoute srv01.uniheberg.fr:25540 en multijoueur.

Windows affiche « Windows a protégé votre ordinateur » ?

C’est normal : le launcher n’est pas signé numériquement — un certificat coûte plusieurs centaines d’euros par an, difficile à justifier pour un serveur entre amis. Windows affiche cet avertissement pour tout programme encore peu téléchargé.

  1. Clique sur Informations complémentaires
  2. Puis sur Exécuter quand même

L’avertissement n’apparaît qu’à la première installation.

Questions

FAQ

Faut-il installer Forge ou Java soi-même ?

Non. Le launcher télécharge le runtime Java 17 officiel de Mojang s’il n’en trouve pas sur ta machine, installe Forge 47.4.10 et synchronise les mods. Tu n’as rien à configurer.

Le serveur a-t-il une whitelist ?

Non, le serveur est ouvert. Il suffit d’avoir le modpack — donc le launcher — pour pouvoir te connecter.

Puis-je jouer sans le launcher ?

Techniquement oui, en installant Forge 1.20.1 et les 216 mods à la main dans les bonnes versions. En pratique, la moindre différence t’empêchera de te connecter — le launcher existe précisément pour éviter ça.

Mes mondes sont-ils sauvegardés ?

Le launcher archive ton dossier de mondes après une session, en dehors du dossier de jeu, et conserve les cinq dernières sauvegardes. Tu peux en restaurer une depuis les Paramètres.

Le jeu plante au démarrage, que faire ?

Le launcher affiche la fin du journal avec un bouton « Copier pour Discord ». Essaie aussi « Vérifier les mods » dans les Paramètres : un fichier incomplet suffit à faire planter le jeu.

Combien d’espace disque faut-il ?

Environ 6 Go : Minecraft et ses ressources, Forge, les 216 mods, le runtime Java et les sauvegardes. Les Paramètres du launcher affichent la répartition exacte.
