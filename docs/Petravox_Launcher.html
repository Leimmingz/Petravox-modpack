Comment rejoindre

1
Télécharge et lance le launcher Double-clique sur Petravox Launcher.exe — Windows peut afficher un avertissement, clique sur "Exécuter quand même".
2
Connecte ton compte Microsoft Clique sur "Se connecter" — un code s'affiche, entre-le sur microsoft.com/devicelogin. Ton compte doit posséder Minecraft Java Edition.
3
Clique sur Jouer Le launcher installe Forge et tous les mods automatiquement (~2–5 min la première fois). Minecraft se lance tout seul.
4
Rejoins le serveur Ajoute le serveur dans Minecraft : srv01.uniheberg.fr:25540. Le serveur est en whitelist — contacte un admin pour être ajouté.
